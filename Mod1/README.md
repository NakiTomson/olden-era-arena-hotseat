# Арена для двоих — 0.2.1

Мод позволяет двум людям последовательно подготовить героев и управлять своими армиями в локальной арене Olden Era за одним компьютером.

Включите **Арена для двоих** в `Launcher/OldenEraLauncher.exe`, затем откройте **Несколько игроков → Хотсит → Арена** и выберите **Игрок** во втором слоте. Для партии против ИИ оставьте **Игрок-компьютер**.

При передаче подготовки второму игроку его шкала начинается с «Героя», а панели показывают его собственные армию и заклинания. Выбор первого игрока сохраняется. Бой начинается после готовности обоих; общий таймер подготовки в арене для двоих отключён.

Поддерживается **Steam-сборка 25061458**, Windows x64. Работоспособность версии 0.2.1 подтверждена пользователем 13 сентября 2026 года. Это не полная проверка всех героев, заклинаний и сочетаний других модов.
