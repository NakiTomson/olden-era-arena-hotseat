# Проверка Arena Hotseat 0.2.1

Дата: 13 сентября 2026 года. Игра: Steam build **25061458**, Windows x64.

## Игровой результат

Пользователь подтвердил, что текущая версия работает. В 0.2.1 исправлен сброс шкалы подготовки при передаче управления второму игроку: сначала активен этап «Герой», затем шкала заполняется по мере прохождения его подготовки.

Это подтверждение ручного использования. Полный перебор героев, навыков, артефактов, заклинаний и взаимодействия с другими модами не выполнялся. Новая игровая сессия специально для упаковки релиза не запускалась.

## Контрольные значения

- Версия плагина: `0.2.1`; версия сборки: `0.2.1.0`.
- SHA256 `GameAssembly.dll`: `bb4ea1f5b28af6b3f21031bb53f7fa50021579a8c74ade2f05904696d6fdb38a`.
- SHA256 DLL мода: `4f9b1f6632dd8db45d3213d422b0130e6d1d14b246c51c3b243b30864fc95d0f`.

Для реализации 0.2.1 ранее выполнены сборка и сверка 17 нативных сигнатур. Контроль хеша игры и проверка сигнатур также остаются в самом плагине перед установкой перехватов.

При подготовке релиза проверяются хеши всего payload и runtime, отсутствие личного состояния установки в ZIP и интеграционные проверки файловых операций лаунчера. Контрольные суммы архивов опубликованы в `SHA256SUMS.txt` рядом с релизом.

## Известные ограничения

Совместимость повторов не подтверждена. Известная `NullReferenceException` при выходе из арены отложена для отдельного разбора; причастность мода не установлена.

При следующем обновлении используйте [порядок проверки совместимости](../../Launcher/README.md#как-проверять-совместимость-после-обновлений).
