# Olden Era — Арена для двоих

Неофициальный мод для **Heroes of Might and Magic: Olden Era**, который позволяет двум людям сражаться на арене **за одним компьютером**.

Первый игрок выбирает героя, развивает его и собирает армию. Затем подготовка автоматически передаётся второму игроку. Когда оба готовы, начинается бой: игроки по очереди управляют своими отрядами одной мышью и клавиатурой.

**[Скачать готовый комплект 0.2.1 для Windows x64](https://github.com/NakiTomson/olden-era-arena-hotseat/releases/download/v0.2.1/OldenEra-ArenaHotseat-0.2.1-win-x64.zip)** · [Все релизы](https://github.com/NakiTomson/olden-era-arena-hotseat/releases)

В архив входят мод, лаунчер для включения и отключения, BepInEx и нужные библиотеки. Отдельно нужна установленная игра.

## Как играть

1. Распакуйте архив в отдельную папку. Сохраните папки `Launcher` и `Mod1` рядом.
2. Закройте игру и запустите `Launcher/OldenEraLauncher.exe`.
3. Укажите папку игры, отметьте **Арена для двоих** и нажмите **Играть**. Первый запуск с загрузчиком может занять несколько минут.
4. Откройте **Несколько игроков → Хотсит → Арена**.
5. Во втором слоте выберите **Игрок**, сохранив первого игрока в его слоте, и нажмите **Начать игру**.
6. Подготовьте двух героев по очереди и начинайте бой.

Для игры против ИИ выберите во втором слоте **Игрок-компьютер**. Этот вариант остаётся доступен при включённом моде. **Быстрый старт** также сохраняет обычного соперника-компьютер.

Чтобы отключить мод, закройте игру, снимите отметку в лаунчере и нажмите **Применить**.

## Что добавляет мод

- Выбор второго человека в штатном меню локальной арены.
- Автоматическую передачу подготовки второму игроку без окна «ОК».
- Собственные армию и заклинания на панелях второго героя с сохранением выбора первого.
- Сброс шкалы подготовки второго игрока на этап «Герой».
- Управление обеими армиями людьми.
- Подготовку без общего таймера в арене для двоих. В режиме против ИИ таймер работает как обычно.

## Совместимость

Версия мода **0.2.1** рассчитана на **Steam-сборку 25061458**, Windows x64. Для лаунчера нужен .NET Framework 4.8. Работоспособность 0.2.1 подтверждена пользователем 13 сентября 2026 года.

После обновления игры сначала проверьте совместимость. Лаунчер и мод сверяют SHA256 `GameAssembly.dll` и отказываются включать мод на неподдерживаемой сборке. Совпадение хеша дополняется проверкой подготовки, боя и повторной арены.

**[Подробная инструкция, проверка после обновлений и восстановление](Launcher/README.md)** · [Проверка выпуска 0.2.1](Mod1/verification/0.2.1.md)

Оба игрока видят один экран. Мод предназначен для локальной арены; совместимость повторов и других модов не подтверждена. Все сочетания героев, навыков и заклинаний не перебраны. Известная запись `NullReferenceException` при выходе из арены отложена для отдельного разбора; её связь с модом не установлена.

## Исходники

В репозитории находятся исходники лаунчера и мода, скрипты сборки и манифесты. Для запуска скачивайте готовый ZIP из Releases; архив GitHub **Source code** содержит исходники.

- `Launcher/src` — лаунчер и интеграционная проверка файловых операций.
- `Mod1/src` — плагин Arena Hotseat.
- [DEVELOPMENT.md](DEVELOPMENT.md) — сборка и проверка.
- [THIRD-PARTY.md](THIRD-PARTY.md) — зависимости, лицензии и исходники библиотек.

В пакет не включены оригинальные игровые DLL, ресурсы игры, сохранения, личные настройки или журналы. Мод изменяет поведение в памяти процесса и не переписывает `GameAssembly.dll` на диске.

Проект не связан с Unfrozen, Ubisoft или Hooded Horse.
